## Project Overview
ChemDeck is an interactive, web-based flashcard study application (similar to Quizlet or Anki) designed specifically for chemistry students. Rather than relying on static text or uploaded images, ChemDeck uses freeform, in-browser sketching on a two-sided digital flashcard canvas combined with a dedicated reaction scratchpad to allow visual problem-solving and self-graded review.
